### Projeto lab-padroes-projeto-spring
Api Backend java com SpringBoot que consome dados 
Da API do site ViaCEP https://viacep.com.br 
E realiza cadastro em banco dados relacional H2 com Documentação.

org.springframework.boot: version 4.1.1 
java: version 17

### 🔨 DEPENDENCIAS:
spring-boot-starter-webmvc
springdoc-openapi-starter-webmvc-ui: version 3.1.0
spring-boot-h2console
spring-boot-starter-data-jpa
spring-cloud-starter-openfeign

spring-boot-maven-plugin

### 🔨 passo a passo do projeto

- Subir a aplicação java Springboot - http://localhost:8080/ - starter no Application (spring boot dashboard)

 * Projeto Spring Boot gerado via Spring Initializr.
 * Os seguintes módulos foram selecionados:

 * Spring Data JPA
 * Spring Web
 * H2 Database (http://localhost:8080/h2-console)
 * OpenFeign
 * Open Api Swagger ( http://localhost:8080/swagger-ui/index.html )
